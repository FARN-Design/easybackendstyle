# Translation maintenance

English is the source language. Maintain complete de_DE (informal du) and
de_DE_formal (formal Sie) catalogs, including the supported pre-7.0 code path.
Source strings use the literal easybackendstyle domain. JavaScript uses wp-i18n
and wp_set_script_translations. Documentation URLs are translated with the UI.

Requires WP-CLI i18n and GNU gettext (msgmerge, msgcmp, msgfmt, msgattrib):

    python3 scripts/build-translations.py --refresh-pot
    # Translate all missing PO entries, then:
    python3 scripts/build-translations.py --check-source

Use --wp-cli /path/to/wp-cli.phar --php /path/to/php if needed. The build validates
fresh source coverage and placeholders, then generates MO, PHP and JavaScript
catalogs. Both CI and release packaging regenerate and validate catalogs.
English needs no separate catalog. WordPress.org readme content is maintained
separately in README.txt and must never enter plugin UI catalogs. No external
update endpoint is registered; WordPress.org remains the update source.

## Import into translate.wordpress.org

Every successful translation build also writes:

- `docs/generated/plugin-de_DE.po` — German, informal (du).
- `docs/generated/plugin-de_DE_formal.po` — German, formal (Sie).

These are complete plugin UI catalogs (PHP and JavaScript, including the legacy
code path), without obsolete entries. They preserve gettext contexts, plural
forms and placeholders. Do not edit the generated copies; edit the source PO
files in `src/languages` and rebuild. The gated release workflow attaches both PO files
alongside the plugin ZIP, so imports always correspond to that release.

On https://translate.wordpress.org/projects/wp-plugins/easybackendstyle/ choose
the plugin translation project and the matching German variant, then import its
PO file. New English originals must already have been extracted by WordPress.org
from the published plugin source before matching translations can be imported.
Approval depends on the importing account's translation permissions.

These files are **not readme translations**: do not import them into Stable Readme
or Development Readme. Marketplace description translations are a separate
project and are not generated by this UI catalog build.
